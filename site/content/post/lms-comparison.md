# Learning Circles Asynchronous Platform Requirements

## Project Overview
**Objective:** Transition from live 9-week Zoom-based Learning Circles to asynchronous, cohort-based format  
**Goal:** Preserve connection and accountability while improving flexibility and scalability  
**MVP Scope:** Fully asynchronous cohort experience for 25-50 participants
